# V13.3 · Financial integration (Beta)

Futuro now uses date-based flexible plans when enabled, keeping non-overlapping legacy plans as fallback. A legacy allocation intersecting a native plan is excluded whole; coverage gaps are reported, not silently prorated. Income is projected using the saved plan amount and current category calendar; matching dated real income replaces the projection, and undated income is not assumed. Future actual movements and savings reduce remaining allocations; debt minimum scheduling and excess-budget logic remain. Scenario and debt simulator receive the same forecast. The budget view exports selected range category totals in CSV, with unknown plan values blank. The old standalone Reports module is disabled in this repository and is not reintroduced. The ledger, reconciliation, mobile import protocol and legacy period identifiers remain unchanged; dates outside the legacy calendar still need compatible periods. Full migration away from legacy identifiers is not part of this beta. Tests include overlap, gap warnings, mobile-origin expense, known income and horizon consistency. Existing storage keys and version label remain unchanged.
