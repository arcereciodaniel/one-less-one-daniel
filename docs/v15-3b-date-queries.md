# V15.3b — week and custom date range

Candidate only, no production deployment. Shared V15 query engine now runs in Node and the browser without a duplicated implementation. Weeks are Monday–Sunday; custom dates inclusive. A single existing selector and existing date arrows are used; date inputs appear only in custom mode. Actuals are registered movements by actual date, including linked savings contributions once; unassigned partial budgets are not prorated. Complete-period subtotals are explicitly distinguished from total allocation. Original budget cards and their editing remain for financial periods. Date views are read-only and disable quarter maintenance actions. UI preferences only; no financial persistence changes or CSS changes. The actual-ledger audit and any V13/V14 reconciliation are not completed. A separately published Lab preview and user approval are still required before production.
