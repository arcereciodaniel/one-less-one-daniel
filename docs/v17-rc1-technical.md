# V17.0 RC1 técnica — no publicable
Copia aislada del HTML nativo de Lab con sus calculadores, datos sintéticos, claves exclusivamente rastro_lab_v17_rc1_preview_, red bloqueada y restauración deshabilitada. El workspace flexible único usa el DOM nativo oculto para arrancar el motor; no es aún un reemplazo integral del shell publicado. El editor guarda la extensión validada a través de oneStoragePersist y conserva fuente, respaldo y hechos. Se leen de nuevo los datos al recargar. La visualización usa mes calendario (quincena 1–15 y 16–fin), mientras la asignación salarial histórica se conserva intacta; no se redefine el mes financiero. Totales CRC/USD convierten plan con tasas actuales y ejecución con snapshot histórico, detalle por moneda original; no se inventa FX ausente. El saldo operativo se calcula con la función nativa para la fecha simulada. Futuro muestra variación parcial de flujos fechados, sin sumar compromisos duplicados ni afirmar saldo futuro definitivo. 
Bloqueos: registro/edición de movimientos y acciones originales de herramientas secundarias aún no están conectados al nuevo workspace, reconciliación del mes financiero vs calendario, proyección completa de liquidez y disponible estimado, validación de exportación/restauración de overlay, todas las pruebas visuales de la RC y auditoría privada de datos reales.
