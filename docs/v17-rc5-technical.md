# RC5 — Vínculos de compromisos
Un vínculo explícito uno-a-uno entre previsión de proyecto y asignación fechada de gasto, misma moneda y fecha. No crea movimientos ni aumenta presupuesto. Solo se considera cubierto cuando el flujo residual incluido coincide exactamente con el pendiente de proyecto. Si cambia el importe, fecha o asignación, revisar; no sumar automáticamente. Persistencia en campo separado, verificación de copia guardada y respaldo. La restauración verifica estructura y muestra vínculos desactualizados; no convierte cobros en ingresos automáticamente, porque pueden ser reembolsos. Se recuperan acciones nativas de editar y conciliar previsiones y consultar historial de cobros con sus acciones originales. Pendientes: pruebas completas de las operaciones, enlace de cuotas de deuda y clasificación explícita de cobros antes de considerar liquidez completa, archivos/administración y aprobación de UX. Candidata de datos ficticios, almacenamiento independiente, no publicar.
