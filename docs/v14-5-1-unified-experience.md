# V14.5 · Unified experience correction

Budget has one visible R8-style view, independent of the previous Beta toggle. The header contains one period selector, previous/next and Today; the view and breakdown preference are saved only to UI storage. Original renderer remains hidden for old period/record maintenance and regression compatibility. Expense amounts open a compact individual editor, income opens category configuration, unused categories collapse, breakdown is optional, and distribution uses the existing dated replacement engine. No new storage keys or financial migration. Original quarter controls remain reachable in Settings. Home and Movements hide the duplicated selector when their universal mode is inactive; existing date controls retain the More periods entry point for a safe transition. No visual browser verification on the user's local data. The mobile importer still requires legacy period IDs. Historical copy-month/technical editing is not exposed in the new budget view; later review should unify these actions safely. The release remains v14.5 and tests expecting the old label are corrected, not disabled.
