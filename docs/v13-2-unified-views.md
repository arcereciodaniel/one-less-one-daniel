# V13.2 · Unified date views (Beta)

Home, Budget and Movements share flexible date selection and navigation. Home uses the same native/legacy coverage and date-based category totals as Budget, actuals through today, and shows unknown plan totals when coverage is incomplete. Available estimate uses today's configured cycle, not the selected historical view. Goal previews use the selected range; CSV retains legacy identifiers and appends flexible boundaries. Mobile imports already preserve dates and trigger view refresh, and are included in the same date scope; the existing mobile/desktop legacy period creation requirement remains for out-of-range imports. No migration of balances or movement IDs. Future and reports retain the legacy projection model until further work. Legacy view remains accessible. Tests cover inclusive dates, category commitments, native plan, mobile-origin movement and savings.
