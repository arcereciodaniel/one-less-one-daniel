# V16.6 — UX minimalista
Prototipo aislado. Navegación centrada con módulos esenciales siempre visibles y botón + final para habilitar herramientas opcionales. Se mantiene la selección temporal al cambiar de herramienta. Un único selector junto al título, mes navegable y desplegable de semana/quincena con opción Todas/Ambas; Actual es un atajo, no un modo obligatorio. En intervalos agregados se oculta el selector innecesario. Inicio deja de repetir las tarjetas de presupuesto. Se reducen textos, bordes, espacios, sombra y duplicación de controles; ajustes responsivos y tema monocromático con estructura idéntica. No cambia CSS de producción. Se conserva el editor y sus revisiones, la separación de monedas originales y alertas de integridad. No se implementa aún un cambio de moneda global en la demo; no se agrega control simulado. Las herramientas habilitadas y cambios son volátiles. No se conecta almacenamiento real. Decisión de diseño: solo módulos esenciales visibles al iniciar la demo, las demás herramientas se habilitan mediante +. No se cambia la configuración del usuario real. Pendientes: auditoría V16.7, integración nativa y pruebas visuales antes de lanzamiento.
