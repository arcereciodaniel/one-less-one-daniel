# V14.0 · Universal Time Engine

The universal interval selector is available without enabling the V13 beta, while the original editor remains accessible. Weekly, fortnightly, monthly, quarterly, calendar semester, calendar year and custom dates share the same in-session selection. Existing expense allocations are proportionally displayed by days with cent conservation. Dated income appears on payment dates; undated amounts appear only for full source intervals. Coverage gaps are explicit. This is a read-only distribution, not yet the V14.1 unified editable ledger; forecasts and available-estimate keep existing semantics. No financial data is changed by selecting a view. Lab offers a confirmed snapshot copy from Daniel on the same browser/origin using the existing restore preview and protective backup. Lab cannot write to Daniel, no cloud sync or mobile credentials copied. Legacy storage keys unchanged.
