# V16.7 — Persistencia experimental y auditoría
Se conserva el ledger V16.0 y se agrega únicamente una extensión versionada v16AssignmentOverlay. Las distribuciones guardan el identificador y contenido de origen, reemplazan su representación solo en el motor nuevo y conservan total, moneda y período financiero. Las nuevas asignaciones se consultan por calendario; no entran en los cálculos financieros históricos nativos. Cambios en el presupuesto de origen bloquean la carga de la distribución, no borran el histórico. Los movimientos nuevos se leen del ledger actualizado, no de una copia congelada. La operación se prepara y revalida, se comprueba el respaldo byte por byte y se usa un callback de persistencia existente. No se promete atomicidad entre pestañas (localStorage carece de CAS). 
Pruebas de formato, restauración por recarga, protección de movimientos y saldos, y guardado con guardia nativa de Daniel/Lab, exclusivamente con fixtures. No se activa en el producto publicado. El auditor HTML local reutiliza el chequeo estático V16.0, no inspecciona overlay real ni certifica saldos. No subir respaldo ni datos privados. La visual V16.6 falló antes de ejecutar por Ubuntu 26.04 incompatible; nuevo workflow usa Ubuntu 24.04.
Pendientes de lanzamiento: conectar editor y vistas al ledger real (no solo pruebas), incluir nuevas asignaciones en proyección financiera y saldo disponible sin duplicación, resolver semántica calendario/mes salarial, moneda global, conciliación de datos reales, UX y aprobación. V17 no está listo para publicación.
