## Recovery hardening (pre-release only)
If activation fails after persisting the exact original, the user can reselect the same backup or portable session; the original must match byte-for-byte. A different source, a changed active snapshot or an already-active private session is rejected. Existing active private copies must never be overwritten through this path. Automated tests inject a failed active write and verify that a retry does not rewrite the original. This is recovery within the isolated candidate, not a production downgrade strategy. The Cloudflare deployment job on this branch is additionally guarded to main only; no deployment is invoked here.
