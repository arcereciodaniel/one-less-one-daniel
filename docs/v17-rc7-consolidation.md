# RC7 — Consolidación
Inicio recupera disponible estimado con saldo operativo nativo, egresos pendientes del mes salarial y nuevas asignaciones mapeadas a un período original único. Conserva la asignación histórica como base y calcula solo el residual incremental por categoría/período, con consumo aplicado una vez. Si falta saldo, período, presupuesto, FX o conciliación, muestra —. No incluye ingresos futuros ni obligaciones no presupuestadas. No equivale a liquidez garantizada. Se recuperan conciliación de saldo, categorías, tipos de deuda, FX, ajuste de deuda, archivo de deuda/meta y conceptos de proyectos, reutilizando diálogos y acciones nativos. Pruebas específicas de persistencia de clasificación de cobro, navegación y disponible; las demás operaciones requieren pruebas adicionales. No se agregan filtros ni módulos. Candidata aislada, no apta para producción; pendiente validación integral nativa (incluye recurrencias, móvil, cobros en USD, exportación y restauración real), validación visual y conciliación privada. El desarrollo debe cerrar brechas concretas en vez de aumentar funcionalidades.
