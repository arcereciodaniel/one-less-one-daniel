# V14.1 · Unified Budget Engine

Universal budget views now allow editing expense and debt categories for a selected interval. Dated daily replacements preserve unaffected dates and categories and override, rather than add to, legacy/V13 allocations. Existing plans remain unchanged. Changing a parent interval replaces earlier child edits inside it; confirmation reports the change. Daily cents sum to the entered amount, including partial weeks. Income remains governed by its existing schedule. Adjustments are stored in livingBudgets, included in local backups, validated on load/restore, and never mutate movements. USD uses the chosen currency and current payment FX; unchanged fields are untouched. Partial known category amounts are marked, not treated as complete coverage. Future remains on the prior forecast and warns when V14 edits intersect its horizon. V14.2 will add expansion and redistribution UX; V14.4 will consolidate the forecast. No changes to mobile keys or Lab snapshot mechanism.
